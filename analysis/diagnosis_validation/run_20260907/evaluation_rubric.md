# Blind human evaluation rubric

방식명은 숨기고 사례별 두 출력을 같은 평가자가 짝지어 본다. 출력 순서는 seed로 무작위화했다. 우리 규칙의 문구를 정답으로 사용하지 않으며 복수의 합리적 순서를 허용한다.

전문가(1~5): 근거 일치, 점검항목 적절성, 우선순위 타당성, 원인단정 억제, 불확실성, 조건부 후보 적합성.
점주(1~5): 이해도, 현실성, 질문 부담. 실제 소요시간(초)은 직접 측정한다.

최소 2명 이상을 권장한다. 사례를 독립 표본으로 두고 평가자 반복을 지역표본으로 세지 않는다. 출력 확인 전에 rubric을 고정한다. 현재 상태는 AWAITING_HUMAN_EVAL이다.
