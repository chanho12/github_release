# BC카드 제공 데이터

## 파일과 범위

| 항목 | 값 |
|---|---|
| 파일 | `ABP_CONTEST_DATA.csv` |
| 기간 | 2026년 1~6월 |
| 행 수 | 242,574 |
| 지역 | 255개 `SIDO_NM+CCG_NM` 조합 |
| 업종 | BC 자체 업종 11개 |
| 원자료 단위 | 월×시도×시군구×성별×연령×업종 |

## 컬럼

| 컬럼 | 의미 | 주의 |
|---|---|---|
| `STRD_YYMM` | 기준년월 | 202601~202606 |
| `SIDO_NM` | 시도 | 지역 복합키 구성요소 |
| `CCG_NM` | 시군구 | 단독키 사용 금지 |
| `GENDER_CD` | 성별·외국인·법인 코드 | 국내개인 분석과 분리 필요 |
| `AGE_CD` | 연령 코드 | 숫자 연령에 외국인이 포함될 수 있음 |
| `TP_BUZ_NO` | BC 자체 업종코드 | 외부 표준산업코드와 직접 동일하지 않음 |
| `TP_BUZ_NM` | BC 자체 업종명 | 총 11개 업종 |
| `amt` | 이용금액 | 금액 합계 |
| `cnt` | 이용건수 | 고객 수가 아닌 결제건수 |

## 확인된 제약

- 폐업·개업·공급점포·고유고객·재방문·신규고객·상품·가격·원가 변수가 없다.
- 2025년 동월이 없어 전년동월 계절성 통제가 불가능하다.
- CNT 최솟값이 11이고 1~10이 없어 silent suppression 가능성이 있으나 공식 규칙은 없다.
- 갈비전문점과 한정식의 지역 커버리지가 낮아 미관측을 0으로 처리하면 안 된다.
- `AMT/CNT`는 건당 평균 결제금액이며 가격·마진·이익이 아니다.

## GitHub 공개

원본 CSV는 로컬 패키지에는 배치했지만 `.gitignore`에 포함했다. 주최 측의 재배포 조건을 확인하기 전에는 공개 저장소에 강제로 추가하지 않는다.
