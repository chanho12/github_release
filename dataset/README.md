# 데이터셋 안내

## 1. BC카드 데이터

- 공식 위치: `bc_card/ABP_CONTEST_DATA.csv`
- 코드 호환 위치: `ABP_CONTEST_DATA.csv`
- 코드북: `bc_card/CODEBOOK_legacy.md`
- 설명: [bc_card/README.md](bc_card/README.md)

두 CSV 경로는 로컬에서 같은 파일을 가리킨다. GitHub에는 재배포 권한 확인 전 업로드되지 않도록 제외했다.

## 2. 외부데이터

외부자료는 `외부데이터/`에 기관·목적별로 정리했다.

- 주민등록 연령인구
- 국세청 가동사업자
- LOCALDATA 영업·개업·폐업 인허가
- 전국 폐업 인허가 재구성 패널
- 기상청 기상월보·ASOS
- 법무부 등록외국인
- 정확 업종 수요·공급 통합패널

출처와 허용 역할은 [외부데이터/SOURCES_AND_USAGE.md](외부데이터/SOURCES_AND_USAGE.md)를 참고한다.

## 3. 호환 경로

`external_raw/`, `localdata_raw/`, `폐업률/`, `processed/`는 기존 분석 코드가 기대하는 입력 경로다. 새 분석의 설명 문서와 품질표는 `외부데이터/`를 우선 진입점으로 사용한다.

## 4. 공통 키

- 월: `STRD_YYMM`
- 지역: `SIDO_NM + CCG_NM`
- BC 업종: `TP_BUZ_NO + TP_BUZ_NM`

`CCG_NM`만 사용하면 동명 시군구가 충돌할 수 있다. 외부업종은 BC 업종과 동일한 코드체계가 아니므로 매핑 신뢰도를 반드시 함께 사용한다.

## 5. 데이터 사용 원칙

- 미관측을 0으로 대체하지 않는다.
- 현재 스냅샷을 과거 월 값으로 복제하지 않는다.
- CNT를 고객 수로 표현하지 않는다.
- 인허가 수를 BC 가맹점 수로 표현하지 않는다.
- 원자료와 가공자료의 출처·기간·체크섬을 구분한다.
