# BC카드 외부데이터 확보·검증 결과

## 1. 결론

요청한 외부자료를 `dataset/외부데이터/`에 정리했다. 2026년 1~6월을 실제로 충족하고 BC 데이터의 설명 후보를 좁히는 자료는 **주민등록 연령인구**와, 정확 매핑 업종에 한정한 **국세청 가동사업자·LOCALDATA 영업점**이다.

기상청 월보는 1~6월 원본을 새로 확보했지만 시군구 직접 매칭 범위와 실제 피크 설명력이 부족해 핵심분석에서 제외한다. 법무부 등록외국인은 3월·6월 시군구 스냅샷을 새로 확보했으나 6개월 월별 패널이 아니어서 외국인 소비 원인 모듈에서 제외한다.

> 외부데이터를 붙였다고 모든 원인을 알 수 있게 된 것은 아니다. 현재 방어 가능한 추가 가치는 `인구 변화 이상의 소비 변화인지`와 `정확 매핑 업종에서 수요와 공급 방향이 같은지`를 구분하는 데 있다.

## 5. 기상 피크 검증 결과

전국 동일업종 대비 지역 AMT 점유율의 월별 변동과 기상지표를 6개월 동안 비교했다.

- 분석 가능 조합: 685개 지역×업종, 77개 지역
- 기존 피크 의존 조합 중 기상 연결 가능: 89개, 52개 지역
- 6개월 CNT 10만건 이상 피크 의존 조합: 31개, 21개 지역

피크 의존 89개에서 중앙 Spearman 상관은 다음과 같았다.

| 기상지표 | 중앙 rho | BC 피크월과 기상 최대월 일치 |
|---|---:|---:|
| 평균기온 | -0.029 | 8.99% |
| 총강수량 | -0.029 | 25.84% |
| 일조시간 | -0.086 | 24.72% |
| 1mm 이상 강수일수 | -0.145 | 5.62% |

거래 10만건 이상 31개에서도 중앙 상관은 평균기온 -0.314, 강수량 -0.086, 일조시간 -0.257, 강수일수 -0.185였다. 방향이 일관되지 않고 월 관측치가 6개뿐이며 지역 커버리지도 30.20%다.

**판정: 약함~기각.** 기상은 개별 사례의 추가 질문 후보로는 볼 수 있지만, 현재 데이터에서 특정 월 피크의 반복 원인으로 채택할 근거가 부족하다. 세부 결과는 `analysis/external_data_acquisition/run_20260907/weather_spike_summary.csv`에 있다.

## 6. 최종 서비스에서의 역할

1. 주민등록인구: 연령별 BC 소비 변화가 단순 주민구성 변화와 같은 방향인지 확인하는 **핵심 통제 카드**.
2. 국세청·LOCALDATA: 정확 매핑 4개 업종에서 수요와 공급 방향을 구분하는 **제한 진단 카드**.
3. 기상: 자동 원인판정에는 사용하지 않고, 지역·월이 연결될 때만 보여주는 **사례 확인 정보**.
4. 등록외국인: 현재는 2개 스냅샷이므로 **보류/제외**. 월별 6개 시점이 확보되기 전에는 BC 외국인 소비 원인으로 사용하지 않는다.

## 7. 재현 코드

- 공식 기상·외국인 파일 다운로드: `scripts/download_external_data_2026h1.sh`
- 외부자료 분석패널·품질표 생성: `scripts/prepare_external_data_package.py`
- 기상 피크 제한 검증: `scripts/validate_weather_spike_module.py`

실행:

```bash
bash scripts/download_external_data_2026h1.sh
PYTHONPYCACHEPREFIX=/tmp/bc_external_package_pycache python3 scripts/prepare_external_data_package.py
PYTHONPYCACHEPREFIX=/tmp/bc_weather_module_pycache python3 scripts/validate_weather_spike_module.py
```
