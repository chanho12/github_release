# BC 공모전 외부데이터 패키지

이 폴더는 `ABP_CONTEST_DATA.csv`만으로 확인할 수 없는 인구·공급·기상·외국인 맥락을 검증하기 위해 만든 외부데이터 패키지다. 2026년 1~6월을 임의 보간하거나 현재 자료를 과거 월별 자료로 복제하지 않았다.

## 바로 사용할 파일

| 자료 | 분석용 파일 | 사용 판정 |
|---|---|---|
| 주민등록 연령인구 | `행정안전부_주민등록인구/202601_202606_주민등록_연령인구_분석패널.csv` | 핵심 사용 |
| 국세청 가동사업자 | `국세청_가동사업자/202601_202606_BC정확매핑_가동사업자.csv` | 제한적 사용: 편의점·슈퍼마켓 |
| LOCALDATA 영업점 | `LOCALDATA_영업점/202601_202606_BC정확매핑_영업점.csv` | 제한적 사용: 중국음식·제과점 |
| 기상청 ASOS | `기상청_기상/202601_202606_ASOS_월별관측지점.csv` | 핵심분석 제외, 사례 검토만 |
| 등록외국인 | `법무부_등록외국인/202603_202606_등록외국인_시군구_분기스냅샷.csv` | 핵심분석 제외 |
| BC+외부 통합 | `통합패널/202601_202606_BC_정확업종_수요공급패널.csv` | 정확 매핑 4개 업종용 |

## 왜 일부 자료는 제외했나

- 기상청 월보는 1~6월이 모두 확보됐지만 ASOS 97개 지점만 6개월 완전관측이고, 보수적으로 BC 시군구에 직접 연결되는 지역은 77/255개다. 관측지점 값은 시군구 전체 평균이 아니며 서울·부산 등 광역시 구별 차이도 제공하지 않는다.
- 등록외국인 시군구 상세자료는 2026년 3월 31일과 6월 30일 스냅샷만 확인됐다. 매칭 자체는 254/255개지만 월별 6개 관측이 아니므로 BC 외국인 소비의 월별 추세·피크 원인 검증에는 쓰지 않는다.
- 국세청 가동사업자는 물리적 점포 수와 같지 않고, LOCALDATA 영업점은 BC 가맹점 모집단과 같지 않다. `AMT/supply_count`, `CNT/supply_count`는 점포당 실제 매출·방문수로 표현하면 안 된다.

## 품질·출처 확인

- 자료별 기간·결측·지역 매칭률: `통합패널/external_data_quality_audit.csv`
- 공식 출처와 확보 방법: `통합패널/source_metadata.csv`
- 패키지 파일 SHA-256: `통합패널/checksums_sha256.csv`
- 국세청 원본 위치·해시: `국세청_가동사업자/국세청_원본파일_위치_해시.csv`
- LOCALDATA 대용량 원본 위치·해시: `LOCALDATA_영업점/LOCALDATA_원본파일_위치_해시.csv`

LOCALDATA 원본 3개는 합계 약 883MB라 중복 복사하지 않았다. 원본은 `dataset/localdata_raw/`에 그대로 있으며, 이 패키지에는 경로와 해시 및 분석용 패널을 넣었다.

## 재현

공식 기상·외국인 파일을 다시 내려받으려면:

```bash
bash scripts/download_external_data_2026h1.sh
```

원본/기존 가공본에서 분석 패널과 품질표를 다시 만들려면:

```bash
PYTHONPYCACHEPREFIX=/tmp/bc_external_package_pycache \
python3 scripts/prepare_external_data_package.py
```

필요 패키지: `pandas`, `numpy`, `openpyxl`, `xlrd`.

## 해석 원칙

1. 주민인구는 BC 결제자 수가 아니다.
2. CNT는 고객 수나 방문자 수가 아니라 결제건수다.
3. 공급 분모 자료는 BC 가맹점 모집단과 다르다.
4. 기상·외국인 자료가 불완전한 지역에는 원인 라벨을 붙이지 않는다.
5. 결측 월·지역을 0이나 인접 월 값으로 채우지 않는다.
