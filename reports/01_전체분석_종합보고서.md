# BC카드 공모전 전체 분석 종합보고서

## 0. 문서 목적

이 문서는 2026년 1~6월 BC카드 소비데이터를 대상으로 지금까지 수행한 분석·감사·외부데이터 결합·진단 시제품 검증 결과를 하나로 통합한 최종 현황 문서다.

다음 질문에 답하는 것을 목적으로 한다.

1. 데이터에서 실제로 반복되는 소비 변화는 무엇인가.
2. 「같은 매출 변화, 다른 점검」이라는 주제가 성립하는가.
3. 외부데이터를 사용하면서도 소비구조 분해라고 말할 수 있는가.
4. 지역×업종 데이터로 개별 소상공인에게 어디까지 제안할 수 있는가.
5. 기존 우수팀 분석과 비교했을 때 현재 접근의 장점과 약점은 무엇인가.
6. 현재 완료된 것과 아직 검증되지 않은 것은 무엇인가.

본 분석은 현상의 경제학적 원인, 폐업확률 또는 개선안의 매출효과를 증명하는 연구가 아니다. 경영데이터에서 관찰되는 구조 차이를 찾아 **무엇을 먼저 확인할지** 정하는 의사결정 지원 분석이다.

## 1. 최종 결론

### 1.1 최종 판정

> **원래 표현은 MODIFY, 수정된 주제는 조건부 GO다.**

원래 주제인 `소비구조 분해 기반 맞춤형 개선안 제안`은 개별 점포의 고객·상품·가격·원가·영업정보와 실행성과가 없어 그대로는 방어하기 어렵다.

현재 데이터가 지지하는 최종 주제는 다음과 같다.

> **「같은 매출 변화, 다른 점검」 — BC카드 소비구조 분해와 점주 확인정보를 결합한 지역·업종 경영 의사결정 지원 시스템**

발표용으로 “다른 처방”이라는 표현을 사용할 수는 있지만, 실제 기능과 본문에서는 다음처럼 제한해야 한다.

- 처방 → **점검 우선순위**
- 맞춤 개선안 → **점주 답변에 따른 조건부 개선 선택지**
- 위험 예측 → **관찰된 변화 신호**
- 개별 점포 진단 → 점포정보 입력 전에는 **지역×업종 진단**

### 1.2 가장 중요한 데이터 결론

현재 데이터의 대표 현상은 `AMT는 증가하지만 CNT는 감소하는 성장착시`가 아니다.

> **전국적으로 CNT가 AMT보다 빠르게 증가하고 건당 평균 결제금액은 하락하는 거래량 중심 성장이 나타났으며, 같은 AMT 변화 안에서도 CNT·건당 결제금액·지역총량 대비 업종 방향·소비층 구성·피크 의존성이 다르게 나타났다.**

핵심 수치는 다음과 같다.

| 결과 | 규모 |
|---|---:|
| 전국 AMT 월 로그 성장률 | +1.68% |
| 전국 CNT 월 로그 성장률 | +3.64% |
| 전국 건당 결제금액 월 로그 성장률 | -1.89% |
| AMT 성장 지역 중 CNT 증가·건당 결제금액 하락 | 209/230, 90.87% |
| 지역총량·개별업종 방향 불일치 | 679/2,327 |
| 위 불일치 중 실제 상승·감소 정반대 | 496 |
| 지역총량 상승·개별업종 감소 | 432/2,327 |
| 인구보다 60대 이상 소비점유율이 빠르게 증가 | 203/251 |
| 7개 공통업종 CNT 집중도 증가 | 207/254 |
| 엄격한 원단위 AMT+·CNT- 후보 | 10/2,327, 0.43% |
| 폐업률 모형 최상 교차검증 R² | 0.020 |
| 순점포 변화 모형 최상 교차검증 R² | 0.016 |

따라서 성장착시나 폐업예측을 중심 주제로 삼기보다, **같은 매출 변화의 내부 경로를 분해해 점검 순서를 바꾸는 것**이 가장 강한 방향이다.

## 3. 분석 진행 과정과 결론 변화

### 3.1 1차: 성장착시 탐색

초기 정의는 `AMT slope>0, CNT slope<0`이었다.

| 결과 | 규모 |
|---|---:|
| 절대 성장착시 후보 | 10/2,327, 0.43% |
| 전국 동일업종 추세 제거 상대 후보 | 134/2,327, 5.76% |
| 절대·상대 동시 충족 | 4개 |
| 절대 후보 중 2개월 이상 연속 | 0개 |
| 상대 후보 중 2개월 이상 연속 | 6개 |
| AMT·CNT slope가 모두 p<0.05 | 0개 |

후보는 존재하지만 절대 기준에서 매우 드물고 지속성도 약했다. 상대 후보 대부분은 CNT 자체가 감소한 것이 아니라 전국 동일업종보다 CNT 증가속도가 느린 사례였다.

**결론 변화:** 성장착시를 전국적 위험현상으로 제시하지 않는다. 예외적인 보조 플래그로만 유지한다.

### 3.2 2차: 소비구조 패턴 탐색

`AMT=CNT×건당 결제금액` 항등식을 이용해 성장경로를 분해했다. 같은 6개월 로그회귀에서는 다음이 정확히 성립한다.

`AMT 로그 slope = CNT 로그 slope + 건당 결제금액 로그 slope`

최대 분해오차는 약 `9.16×10⁻¹⁶`으로 수치오차 수준이었다.

- 255개 지역 중 AMT 성장 지역은 230개였다.
- 그중 209개는 CNT 증가가 건당 결제금액 하락을 상쇄했다.
- 지역 전체에서 CNT 감소·건당 결제금액 상승·AMT 증가는 1개뿐이었다.
- 연령 HHI 증가·Entropy 감소 지역은 106/255개였다.
- 외식→생활구매 전환 후보는 AMT·CNT 양쪽 기준 38/255개였다.

4개 탐색 군집은 일반 거래량 성장·외식 유지형 124개, 저성장·다업종 외식 약화형 100개, 군 고성장·고령집중·생활구매 전환형 10개, 군 고성장·고령집중·외식 유지형 21개였다. 다만 군집은 자연적으로 고정된 범주가 아니라 변화 패턴의 요약이다.

**결론 변화:** 핵심 현상을 `성장착시`에서 `거래량 중심 성장과 건당 결제금액 압축`으로 전환했다.

### 3.3 3차: H1~H18 외부결합 심층 탐색

### 3.4 4차: 체류수요·공급·부동산 결합

89개 인구감소지역의 2026년 1~3월에서 체류인구 상대성장과 BC 상대 AMT·CNT 성장의 Spearman 상관은 각각 0.688, 0.630이었다. 하지만 3개월 공통계절성과 제한 표본 때문에 전국 6개월 핵심근거로 사용하지 않는다.

공급자료에서 시장성장·공급과속·점포당 지표 감소형은 31/955, 3.25%로 작았고 AMT와 `AMT/공급분모` 방향은 94.03%가 같았다. 반면 수요감소·공급증가형은 176/955, 18.43% 존재했다.

**결론 변화:** 점포당 기회를 전체 주제로 사용하지 않고, 정확 매핑 업종의 제한적인 수요·공급 점검 카드로 축소했다.

### 3.5 원자료 재검증과 진단 시스템 구현

원자료에서 최종 기준을 다시 계산하고 다음을 수정했다.

- 방향 불일치 679개는 정반대 496개와 정체 포함 183개로 구분한다.
- 지역총량 상승·업종 감소 432개는 지역 수가 아니라 지역×업종 조합 수다.
- 기존 대표 4쌍은 구조 차이가 큰 개발 사례이며 일반 성능표본이 아니다.
- Pair 1·3은 첫 점검·추가 질문·전체 순서가 달랐고 Pair 2·4는 모두 같았다.
- 서로 다른 정의의 성장착시 숫자를 하나로 섞지 않는다.

2,327개 Evidence Card와 규칙 기반 C0 진단을 구현했다. 개발 사례와 지역이 겹치지 않는 내부 평가사례 24개도 만들었다.

## 4. 정의에 따라 달라지는 숫자

서로 다른 보고서의 숫자가 충돌하는 것처럼 보일 수 있으므로 다음처럼 구분한다.

| 지표 | 정의 | 결과 |
|---|---|---:|
| 원단위 성장착시 | 원단위 OLS AMT slope>0, CNT slope<0 | 10개 |
| 로그 성장착시 | 로그 OLS AMT slope>0, CNT slope<0 | 9개 |
| 중립구간 적용 엄격 후보 | AMT>+0.25%/월, CNT<-0.25%/월 | 5개 |
| 피크 의존–최종 주제 검증 | 최대 AMT월 제거 후 상승 미유지 | 273개 |
| 피크 의존–감사 진단규칙 | 최대 양의 로그잔차월 제거 후 +0.25% 미유지 | 257개 |

이 숫자들은 오류가 아니라 정의가 다르다. 발표에서는 성장률 비교에 로그추세와 ±0.25% 중립구간을 사용하고, 피크 규칙은 한 가지 정의로 고정해야 한다. 권장 피크 정의는 감사·진단 규칙과 연결된 **257개 정의**다.

## 5. 최종적으로 남은 핵심 경향성

| 경향 | 뚜렷함 | 역할 |
|---|---|---|
| CNT 성장·건당 결제금액 압축 | 매우 높음 | 핵심 |
| 지역총량·개별업종 방향 차이 | 높음 | 핵심 |
| 업종 포트폴리오 집중·이동 | 높음 | 핵심 |
| 소비연령 구성 변화 | 높음 | 핵심, 모집단 민감도 필수 |
| 특정 월 피크 의존 | 중간 | 안정성 점검 |
| 수요·공급 방향 괴리 | 중간 | 정확 매핑 4개 업종의 제한 모듈 |
| 엄격한 AMT+·CNT- | 낮음 | 예외 사례 |
| 기상에 의한 피크 설명 | 약함~기각 | 핵심에서 제외 |
| 폐업·개선효과 예측 | 기각/미측정 | 서비스 출력 금지 |

### 5.1 같은 AMT 변화의 다른 내부 경로

거래량 10만건 이상 실제 사례에서도 AMT 성장률이 거의 같은데 내부구조가 달랐다.

- 익산시 스넥과 인천 미추홀구 스넥은 AMT가 모두 월 +4.47%였지만, 건당 결제금액은 각각 -0.36%, +0.50%였다.
- 서울 강남구 슈퍼마켓과 수원 팔달구 슈퍼마켓은 AMT가 모두 월 -1.16%였지만 CNT는 각각 -0.30%, +1.01%였다.

이는 AMT만 보면 같은 상태처럼 보이는 사례에 서로 다른 확인 질문이 필요함을 직접 보여준다.

### 5.2 지역 전체와 업종의 차이

±0.25%/월 중립구간에서 지역총량과 개별업종 방향이 다른 조합은 679/2,327개였다. 지역 전체가 성장하더라도 해당 업종이 감소한 조합은 432개였다.

따라서 지역 전체 매출 또는 상권지수를 개별 업종에 그대로 적용하면 점검순서가 잘못될 수 있다.

### 5.3 소비층 구성 변화

전체 숫자연령 기준 집중도 증가 조합은 1,222/2,327개, 국내개인 기준은 1,356/2,327개였고 182개에서 판정이 달랐다. 집중 자체를 위험으로 판단하지 않고 다음을 확인해야 한다.

- 특정 연령의 절대 CNT가 증가한 것인지
- 다른 연령의 CNT가 감소해 비중만 높아진 것인지
- 점포의 실제 목표고객과 같은 방향인지
- 외국인 포함 여부에 따라 결과가 바뀌는지

### 5.4 피크 의존

6개월 slope가 특정 월 제거에 민감한 사례가 반복됐다. 그러나 피크의 원인이 행사·대량결제·휴점·영업일·관측범위·날씨 중 무엇인지는 BC 데이터만으로 알 수 없다.

따라서 피크 신호의 목적은 원인을 붙이는 것이 아니라 **장기 추세로 해석하기 전에 해당 월을 먼저 확인하게 하는 것**이다.

## 6. 외부데이터 확보와 최종 사용범위

외부데이터의 역할은 소비구조를 대신 만드는 것이 아니다.

> **BC 데이터로 소비구조를 분해하고, 외부데이터로 인구·공급·환경 설명의 가능성을 제한적으로 확인한다.**

따라서 외부데이터를 사용하더라도 `소비구조 분해`라는 표현은 타당하다. 단, BC 내부 분해와 외부 시장맥락 분석을 구분해야 한다.

### 6.1 최종 자료 판정

### 6.2 인구 보정이 추가한 가치

BC 국내개인 연령코드 2~6과 주민 20대~60대 이상을 비교한 주분석은 11,083개 지역×업종×연령이었다.

- 인구보다 CNT가 +0.25%p/월 이상 빠른 사례: 8,023개, 72.39%
- 인구보다 CNT가 -0.25%p/월 이상 느린 사례: 2,460개, 22.20%
- 동일업종·연령 공통추세까지 제거해도 양·음 Gap이 모두 남았다.

이는 주민수 증가만으로 BC 결제 변화를 설명할 수 없다는 점을 보여준다. 그러나 `BC CNT/주민수`를 주민 1인당 실제 이용횟수로 부르지는 않는다.

### 6.3 공급자료가 추가한 가치

정확 매핑 4개 업종의 1,009개 완전 지역×업종 패널에서 CNT와 공급 방향은 다음과 같았다.

| 유형 | 조합 | 비율 |
|---|---:|---:|
| 소비 증가·공급 증가 | 282 | 27.95% |
| 소비 증가·공급 감소 | 239 | 23.69% |
| 소비 감소·공급 증가 | 31 | 3.07% |
| 소비 감소·공급 감소 | 27 | 2.68% |
| 정체 포함 | 430 | 42.62% |

공급성장과 BC AMT·CNT 성장의 전체 Spearman 상관은 거의 0이었다. 공급자료는 원인을 입증하지 않지만 `수요부터 볼지`, `공급·경쟁환경도 함께 볼지` 질문 순서를 나누는 데 의미가 있다.

### 6.4 새로 확보한 기상·외국인 자료

기상청 2026년 1~6월 기상월보 6개와 법무부 2026년 3월·6월 등록외국인 시군구 상세 원본을 `dataset/외부데이터/`에 저장했다.

기상 피크 검증은 685개 지역×업종, 77개 지역에서 가능했다. 피크 의존 89개에서 평균기온·강수량·일조시간·강수일수와 상대 AMT의 중앙 Spearman rho는 -0.145~‑0.029 수준으로 일관된 설명력이 없었다. 거래 10만건 이상 피크 사례도 31개뿐이었다.

**판정:** 기상은 약함~기각. 등록외국인은 2개 시점뿐이므로 6개월 외국인 소비 원인 분석에서 제외한다.

## 7. 제안하는 진단 시스템

### 7.1 서비스 수준

현재 만들 수 있는 것은 `개별 점포의 자동 처방 시스템`이 아니라 다음의 의사결정 지원 시스템이다.

```text
지역·업종 선택
→ 근거카드 확인
→ 소비구조 분해
→ 최대 3개 추가 질문
→ 점주 답변으로 원인 후보 축소
→ 조건부 개선 선택지 2~4개 제시
→ 점주가 선택
→ 확인 KPI와 점검기간 제시
```

점주가 여러 선택지 중 직접 고르는 방식은 현재 데이터에 가장 적합하다. 데이터가 확인하지 못한 현장정보를 점주가 보완하며, 시스템은 선택지를 근거·조건·성과지표와 함께 제시한다.

### 7.2 개인화 단계

| 단계 | 사용 정보 | 가능한 출력 |
|---|---|---|
| 1. 점포정보 없음 | BC 지역×업종·가용 외부자료 | 지역·업종 점검 우선순위 |
| 2. 점주 질문 답변 | 할인·상품·영업일·주 고객층 등 | 조건부 개선 선택지 |
| 3. 점포 POS·고객정보 | 상품·가격·고객·채널·영업시간 | 점포별 정밀 진단 후보 |
| 4. 실행 전후 데이터 | 선택안·기간·KPI·대조기준 | 개선효과 검증 |

현재 프로젝트는 1단계를 구현했고 2단계의 질문·분기 구조를 만들었다. 3·4단계는 실제 점포자료와 현장실험이 필요하다.

### 7.3 Evidence Card

2,327개 지역×업종 카드에는 다음이 포함된다.

- 월별 AMT·CNT·건당 결제금액
- 로그 성장률, 방향, 강건성
- 전국 동일업종 대비 상대추세
- 지역총량과 개별업종의 방향 차이
- 전체 숫자연령과 국내개인 연령집중 민감도
- 업종구성과 피크 의존성
- 사용 가능한 공급·인구 모듈
- 원자료 추적키, 결측·매핑 한계, 금지 해석

### 7.4 진단 규칙

최종 구현 순서는 다음과 같다.

1. 피크 민감도
2. 지역총량·개별업종 차이
3. CNT 경로
4. 건당 결제금액 경로
5. 연령·업종 구성집중
6. 정확 매핑 공급정보

각 규칙은 `관찰된 신호 → 필요한 정보 → 질문 → 답변 분기 → 조건부 선택지 → KPI → 유보조건`을 가진다. 점포 답변이 없으면 개선 후보는 `PENDING_REQUIRED_ANSWER` 상태로 남는다.

### 7.5 출력 예시

| 관찰 신호 | 추가 질문 | 답변 후 가능한 선택지 | 확인 KPI |
|---|---|---|---|
| CNT 증가·건당 결제금액 하락 | 할인·저가상품·결제분할이 늘었는가 | 세트구성, 추가구매, 할인 수익성 점검 | CNT·건당 결제금액·공헌이익 |
| 특정 연령 비중 증가 | 실제 점포의 주 고객층도 변했는가 | 해당층 강화 또는 다른 연령 접근성 시험 | 연령별 주문·신규고객·재방문 |
| 피크 의존 | 해당 월에 행사·휴점·단체결제가 있었는가 | 반복행사 유지 또는 비수기 보완 | 행사 제외 매출·재구매·영업일 |
| 소비 감소·공급 증가 | 주변 동종 점포가 실제로 늘었는가 | 차별화·시간대·상품·채널 시험 | 점포 CNT·상품믹스·시간대매출 |

이 선택지는 일반적인 후보이며 점주 답변과 점포 KPI가 없으면 추천 확정으로 표현하지 않는다.

## 9. 기존 우수팀 사례와 비교

프로젝트에 저장된 우수사례 PDF 1개는 파일명상 1등팀 자료이나 현재 BC 공모전과 동일 대회·데이터인지 확인되지 않았다. 따라서 확보한 우수사례 1건과의 방법 비교로만 사용한다.

| 비교 | 확보한 우수사례 | 현재 프로젝트 |
|---|---|---|
| 질문 | 어떤 점포가 폐업·급락할 것인가 | 같은 AMT 변화에서 무엇을 먼저 확인할 것인가 |
| 분석 단위 | 개별 가맹점 | 지역×업종, 이후 점주 답변 |
| 방법 | 생존분석·ML·SHAP | 소비구조 분해·Evidence Card·규칙 분기 |
| 핵심 데이터 | 폐업일·개설일·고객·재방문·배달 등 | AMT·CNT·업종·연령·월 |
| 출력 | 위험도·위험요인 | 확인된 사실·질문·선택지·유보 |
| 강점 | 점포 정밀도와 예측 | 낮은 데이터 요구량·전국 적용·투명성 |
| 약점 | 고품질 장기 점포데이터 필요 | 점포 원인·개선효과 직접 판정 불가 |

현재 접근의 장점은 우수팀보다 예측성능이 높다는 것이 아니다.

1. 폐업·고객 데이터가 없어도 전국 지역×업종에서 시작할 수 있다.
2. 모델 입력 전 AMT가 만들어진 구조를 먼저 분해한다.
3. 어떤 수치가 어떤 질문을 활성화했는지 추적할 수 있다.
4. 자료가 없으면 판단을 유보한다.
5. 점주에게 모든 정보를 요구하지 않고 신호와 관련된 최대 3개 질문부터 제시한다.
6. 이후 정밀 점포모형 앞단의 사전 진단·정보수집 계층으로 연결할 수 있다.

불리한 점도 명확하다. 개별 점포 위험도, 고객 이탈, 상품별 문제, 개선효과는 현재 분석으로 알 수 없다.

## 10. 발표에서 사용할 핵심 분석

발표는 다음 4개로 압축하는 것이 가장 적절하다.

### 10.1 AMT 성장경로 분해

같은 AMT 변화가 CNT와 건당 결제금액의 서로 다른 조합으로 만들어진다는 것을 실제 쌍으로 보여준다.

### 10.2 지역총량·개별업종·전국 benchmark 3단 비교

지역 전체가 성장해도 개별업종은 감소할 수 있고, 절대성장과 전국 동일업종 대비 상대성장이 다를 수 있음을 보여준다.

### 10.3 소비층·업종 구성 변화

연령 집중, 국내개인/전체 판정 차이, 업종 포트폴리오 집중을 함께 제시한다. 집중을 위험으로 단정하지 않고 점검 질문으로 연결한다.

### 10.4 피크 안정성과 조건부 질문

6개월 추세가 특정 월에 의존하는지를 확인하고, 해당 월의 행사·영업일·대량결제 등 점주만 아는 정보를 최대 3개 질문으로 수집한다.

주민인구 보정과 정확 매핑 공급자료는 위 핵심 분석을 보완하는 외부 근거 카드로 제시한다. 기상·외국인·폐업은 핵심 슬라이드에서 제외한다.

## 11. 주장 가능한 범위

### 11.1 주장 가능

- 같은 AMT 변화에서도 CNT·건당 결제금액·구성·피크 경로가 다르다.
- 지역총량과 개별업종 방향 차이가 반복적으로 존재한다.
- 전국 동일업종 benchmark로 동시기 공통 변화와 지역 상대 위치를 어느 정도 구분할 수 있다.
- 소비층·업종구성·피크 신호로 추가 질문과 점검 순서를 만들 수 있다.
- BC 데이터가 소비구조 분해의 중심이고 외부자료는 통제·제한 모듈이다.
- 점주 답변을 받은 뒤 여러 조건부 선택지를 제공하는 시스템은 현재 데이터 한계와 정합적이다.
- 지역×업종 사전진단 도구는 구현 가능하며 규칙 재현성도 확인됐다.

### 11.2 제한해서 주장

- 소비고령화는 주민인구와 결제자 모집단 차이를 병기한다.
- 공급분석은 편의점·슈퍼마켓·중국음식·제과점에 한정한다.
- 체류인구 결과는 89개 인구감소지역의 1~3월 동행으로 제한한다.
- 개선안은 점포 답변에 따른 후보이며 점주가 선택하고 KPI로 검증해야 한다.

### 11.3 주장 불가

- CNT 감소가 고객 이탈 또는 재방문 감소라는 주장
- 건당 결제금액 하락이 가격·마진·이익 하락이라는 주장
- 연령·업종 집중이 위험이라는 주장
- 날씨나 관광이 피크의 원인이라는 주장
- 지역×업종 결과가 특정 점포에 그대로 적용된다는 주장
- 폐업확률·예상 매출증가율·검증된 처방효과
- C0가 일반 체크리스트나 LLM보다 사람평가에서 우월하다는 주장

## 12. 현재 상황과 다음 단계

### 12.1 현재 위치

현재 프로젝트는 다음 수준에 도달했다.

> **데이터 경향성 발견 → 원자료 재현 → 외부자료 사용범위 감사 → Evidence Card 생성 → 규칙 기반 진단 구현 → 내부 평가패킷 준비**

아직 다음 단계는 완료되지 않았다.

> **실제 점주정보 입력 → 사람 블라인드 평가 → 동일 LLM 비교 → 점포 실행 → KPI 효과 측정**

### 12.2 가장 우선적인 다음 작업

1. 전문가와 점주 최소 2명 이상에게 24개 블라인드 사례를 평가받는다.
2. 동일 모델·출력예산·질문예산으로 일반 LLM B와 진단절차 LLM C를 실행한다.
3. 동의받은 실제 점포에서 영업일·POS·상품·가격·할인·고유고객·재방문 정보를 수집한다.
4. 시스템이 제안한 선택지 중 점주가 하나를 고르고 사전 정의 KPI를 일정 기간 측정한다.
5. 12~24개월 또는 전년동월 BC 데이터를 확보해 계절성과 지속성을 재검증한다.

### 12.3 최종 제품 포지셔닝

가장 방어력 있는 포지셔닝은 다음과 같다.

> **총매출표와 정밀 예측모형 사이의 소비구조 진단·정보수집 계층**

시스템은 정답을 대신 결정하지 않는다. BC 데이터로 먼저 확인할 문제를 좁히고, 점주의 현장정보에 따라 실행 가능한 선택지와 확인 KPI를 제시한다.

## 13. 최종 한 문장

> **현재 데이터는 “같은 매출 변화라도 내부 소비구조가 달라 먼저 확인할 항목이 달라진다”는 주장을 강하게 지지한다. 다만 개별 소상공인에게는 자동 처방이 아니라 지역×업종 근거, 최대 3개의 추가 질문, 점주가 고르는 조건부 선택지, 실행 후 KPI 확인으로 이어지는 의사결정 지원 시스템으로 제시해야 한다.**
