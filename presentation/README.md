# BC카드 업종별 소비구조·상권위험 진단

2026년 1~6월 BC카드 소비데이터와 외부 상권데이터로 업종별 소비구조를 분석하고, 시계열 복합위험 모델·Neo4j·Hybrid GraphRAG을 구현한 프로젝트다.

## 1. 수수 데이터분석

[`code/BC카드_업종별_전체분석_발표용.ipynb`](code/BC카드_업종별_전체분석_발표용.ipynb)에는 데이터 로딩·품질검사·기술통계·볘업·외부데이터 결합·폐업연관성을 분석한다. 모델·Neo4j·GraphRAG 실행 코드는 포함하지 않았다.

```bash
python3 -m pip install jupyter pandas numpy scipy matplotlib scikit-learn
jupyter notebook
```

노트북을 열고 `Restart Kernel and Run All`을 실행한다. 인터넷·API 키가 없이 실행된다.

## 2. 모델·Neo4j·Hybrid GraphRAG

[`model/README.md`](model/README.md)에 설치와 사용법이 있다.

- 최근 3개월로 이용한 다음 달 멀티라벨 위험
- Neo4j 지역·업종·과거·트렌드·사례 관계검색
- OpenAI Embeddings + Neo4j Vector Index 벡터검색
- OpenAI Responses API 대화형 진단·추가질문·실행안
- FastAPI `/diagnose-region`

API 시키릇은 `.env`·노트북·Git에 저장하지 않는다.

## 기행값·재현 경계

- BC 원본의 외부 재배포 가능 여부를 공모전 약관과 팀 정책으로 확인한다.
- `data/`는 대용량 파일을 포함하므로 GitHub에 올리기 전 파일 크기와 재배포 가능성을 확인한다.
- 현재 모델은 개벼 점포 폐업확률이 아니라 지역×업종 위험신호를 출력한다.
