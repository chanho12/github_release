## 추가 신청 필요

### LOCALDATA 인허가정보조회(이력)

- 공공데이터포털에서 업종별 이력 API 활용신청 및 인증키가 필요하다.
- 목적: 최신 스냅샷의 인허가일·폐업일 역산 패널과 실제 변동 이력을 교차검증한다.
- 대상: 일반음식점, 휴게음식점, 제과점영업, 대규모·준대규모점포, 식품판매업(기타), 안전상비의약품판매업소.
- 최신 표준파일 직접 URL은 현재 서버에서 HTTP 403을 반환하여 자동 다운로드되지 않았다.

### 소상공인시장진흥공단 상가(상권)정보 API

- 공공데이터포털 활용신청 및 서비스키가 필요하다.
- 현재 영업 중 상가의 업종코드·주소·좌표·상가업소번호를 제공한다.
- 2025년 분류 개편에서 상가업소번호가 재생성되어 현재 스냅샷만으로 2026년 1~6월 개폐업을 복원할 수 없다.
- 과거 월·분기 스냅샷을 별도로 확보할 때만 과거 공급변화에 사용한다.

## 권장 사용 순서

1. 국세청 전국·시도 개폐업과 시군구 가동사업자 패널 사용
2. LOCALDATA 현재 역산 패널과 국세청 방향 일치 여부 확인
3. LOCALDATA 이력 API 키 확보 후 실제 변동 이력 재검증
4. 소진공 API는 현재 공급밀도에 사용하고 과거 스냅샷 확보 전에는 월별 개폐업에 사용하지 않음
