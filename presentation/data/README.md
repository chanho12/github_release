# GitHub 데이터 배치 안내

이 저장소에서는 BC카드 원본과 GitHub 100MB 한도를 넘는 대용량 LOCALDATA `raw/` 파일을 포함하지 않았다.

## BC 원본 배치

공모전 약관을 확인한 두 다음 경로에 직전 배치한다.

```text
presentation/data/BC카드_제공데이터/ABP_CONTEST_DATA.csv
```

컬럼 정의인 파일명은 해당 폴더의 `컬럼정의.md`에서 확인한다.

## 외부데이터 재추득

가공된 CSV·메타데이터·운본 재현 설명은 아래 문서를 본다.

- `외부데이터/외부데이터_출처_및_재추득_방법.md`
- `외부데이터/폐업원인_점포단위_데이터_재현방법.md`

API 키는 커밋하지 말고 `.env.example`을 복사하여 개인의 환경변수로만 설정한다.
