# 업종별 트렌드·장사 건강도 해석 가이드

## 1. 이 분석의 `장사가 잘 된다`는 뜻

점포별 매출·이익이 아니라 **2026년 상반기 해당 지역×업종의 BC 수요 건강도**를 뜻한다. 아래 5개 조건을 각 20점으로 놓았다.

| 조건 | 판정 | 의미 |
|---|---|---|
| 실질 AMT 증가 | CPI 보정 AMT 월성장률 > 0 | 물가를 제거해도 소비규모 증가 |
| CNT 증가 | 결제건수 월성장률 > 0 | 이용빈도 확대 |
| 피크 제거 증가 | 최고월 제외 AMT 성장률 > 0 | 행사·일회성 피크에 의존하지 않음 |
| 주민인구 보정 우위 | 연령별 벤치마크 보정 Gap 중앙값 > 0 | 인구변화 이상의 수요 |
| 지속 성장 | 6개월 안정성장으로 분류 | 지속성과 방향성 |

결측 조건은 0점으로 처리하지 않고 가용 조건만의 평균을 사용한다. `health_evidence_count`로 근거 개수를 항상 같이 확인한다.

| 점수 | 등급 | 사용 방식 |
|---:|---|---|
| 80~100 | 구조적 강세 | 확장·업셀 실험 후보 |
| 60~79 | 건전성장 | 성장 세그먼트 집중 |
| 40~59 | 관찰·선별개선 | 지역·고객층을 나눠 실험 |
| 0~39 | 위축·즉시점검 | 신규확장보다 재방문·비용·상품구조 진단 |

## 2. 트렌드 분류

- `수요·객단가 동반성장`: CNT와 실질 건당금액이 모두 증가
- `가성비·빈도성장`: CNT는 증가하지만 실질 건당금액은 하락
- `프리미엄·고객단가`: 실질 AMT는 증가하지만 CNT는 감소
- `빈도증가·매출압력`: CNT는 증가하지만 실질 AMT는 감소
- `수요수축`: 실질 AMT와 CNT가 모두 감소
- `물가착시`: 명목 AMT는 증가하지만 실질 AMT는 감소

`24_industry_marketing_trend_cards.csv`의 외부 트렌드는 마케팅 가설이며, BC에서 상품·메뉴 수준으로 검증되지 않았을 수 있다.

## 3. 폐업 위기 지원에 사용하는 순서

1. 11개 업종 전체에서 장사 건강도와 트렌드 유형을 계산한다.
2. 폐업 업종 매핑이 정확한 중국음식·제과점에서만 고폐업 지역을 고른다.
3. 고회전+수요취약은 신규출점 경고와 존속점 비용·재방문 진단을 최우선으로 한다.
4. 고회전 교체시장은 0~3년차 점포 멘토링과 출점 시뮬레이션을 우선한다.
5. 고밀도 경쟁은 500m 경쟁도와 상품·가격대 차별화를 확인한다.
6. 관측변수로 미설명된 지역은 알고리즘의 고위험 판정보다 폐업자 설문을 우선한다.

## 4. 파일

- `22_region_industry_trend_health.csv`: 2,327개 지역×업종 상세 트렌드·건강도
- `23_industry_trend_scorecard.csv`: 11개 업종 요약
- `24_industry_marketing_trend_cards.csv`: 내부지표+외부트렌드+마케팅 가설
- `25_closure_risk_support_targets.csv`: 정확매핑 중국음식·제과점 고폐업 128개 지역 지원 우선순위

## 5. 금지해석

- 점수가 80이라고 개별 점포의 이익이 높다고 말하지 않는다.
- 업종간 점수 차이를 영업이익률 차이로 해석하지 않는다.
- 폐업지원표의 추천을 개별 사업자의 신용·대출·지원 탈락에 사용하지 않는다.
- 6개월 관찰결과를 장기 추세로 단정하지 않는다.
