# 데이터 구성

- `BC카드_제공데이터/`: 2026년 1~6월 BC 원본 CSV와 컬럼 정의
- `외부데이터/`: 분석에 사용한 외부자료 캐시, 매핑표, 출처 및 재취득 방법
- `분석결과/`: 발표용 노트북의 분석 결과표와 검증 파일

BC 원본은 공유 허용 여부를 확인한 비공개 팀 저장소에서만 관리합니다. 공개 저장소로 전환할 때는 데이터 이용 조건을 다시 확인해야 합니다.

LOCALDATA 원본 중 100MB를 넘는 CSV 3개는 [Drive 스냅샷 및 복구 지침](외부데이터/대용량원본_Drive_복구_검증.md)으로 연결했습니다. 나머지 기존 데이터 파일은 GitHub에 포함했습니다. 노트북은 세 대용량 원본 대신 함께 저장한 가공 패널을 읽습니다. 공식 출처와 재취득 방법은 [`외부데이터/외부데이터_출처_및_재취득_방법.md`](외부데이터/외부데이터_출처_및_재취득_방법.md)를 참고하세요.

API 키와 개인 설정 파일은 커밋하지 않습니다.
