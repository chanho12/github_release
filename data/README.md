# 데이터 구성

- `BC카드_제공데이터/`: 2026년 1~6월 BC 원본 CSV와 컬럼 정의
- `외부데이터/`: 분석에 사용한 외부자료 캐시, 매핑표, 출처 및 재취득 방법
- `분석결과/`: 발표용 노트북의 분석 결과표와 검증 파일

BC 원본은 공유 허용 여부를 확인한 비공개 팀 저장소에서만 관리합니다. 공개 저장소로 전환할 때는 데이터 이용 조건을 다시 확인해야 합니다.

LOCALDATA의 일부 전국 원본 스냅샷은 파일당 100MB를 넘으므로 GitHub 일반 파일로는 포함하지 않았습니다. 노트북은 이 원본 스냅샷 대신 함께 저장한 가공 패널을 읽습니다. 원본 취득처와 복구 방법은 [`외부데이터/외부데이터_출처_및_재취득_방법.md`](외부데이터/외부데이터_출처_및_재취득_방법.md)와 [`외부데이터/폐업원인_점포단위_데이터_재현방법.md`](외부데이터/폐업원인_점포단위_데이터_재현방법.md)를 참고하세요.

API 키와 개인 설정 파일은 커밋하지 않습니다.
