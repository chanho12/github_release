# BC카드 업종별 소비·상권 분석

2026년 1~6월 BC카드 소비 데이터와 외부 상권 데이터를 이용한 발표용 분석 저장소입니다. 실행 코드는 노트북 한 파일에 모았고, 입력 데이터·분석 결과·출처 문서는 `data/`에 정리했습니다.

```text
.
├── README.md
├── requirements.txt
├── code/
│   └── BC카드_업종별_전체분석_발표용.ipynb
└── data/
    ├── BC카드_제공데이터/
    ├── 외부데이터/
    └── 분석결과/
```

## 실행

```bash
python3 -m pip install -r requirements.txt
jupyter notebook code/BC카드_업종별_전체분석_발표용.ipynb
```

노트북에서 `Restart Kernel and Run All`을 실행합니다. 노트북은 저장소 루트의 `data/BC카드_제공데이터/ABP_CONTEST_DATA.csv`와 `data/외부데이터/`를 읽습니다. 외부데이터의 출처와 재취득 방법은 [`data/외부데이터/외부데이터_출처_및_재취득_방법.md`](data/외부데이터/외부데이터_출처_및_재취득_방법.md)에 있습니다.

BC 원본 CSV는 공모전 데이터의 비공개 팀 저장소 공유가 허용된 것을 확인한 뒤 포함했습니다. 저장소 접근 권한을 제한하고, 저장소를 공개로 전환하기 전에는 데이터 공개 조건을 다시 확인해야 합니다.

노트북 실행에 필요한 BC·외부데이터 가공 캐시는 포함했습니다. GitHub 일반 파일 한도를 넘는 일부 LOCALDATA 전국 원본 스냅샷은 포함하지 않았으며, 취득 방법은 `data/` 문서에 남겼습니다.

API 키·비밀번호·개인용 설정 파일은 저장소에 올리지 않습니다.
