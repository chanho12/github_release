# 프로젝트 범위와 주장 수준

## 문제

같은 매출 변화도 결제건수, 건당 결제금액, 소비층, 업종구성, 특정 월 의존성이 다르면 먼저 확인할 경영 항목이 달라질 수 있다.

## 서비스 흐름

```text
지역·업종 선택
→ 분석기간·근거 확인
→ 소비구조 분해
→ 최대 3개 추가 질문
→ 점주 답변에 따른 조건부 선택지
→ 점주 선택
→ KPI 확인
```

## 주장 가능

- 같은 AMT 변화 안에 서로 다른 내부 경로가 존재한다.
- 지역 전체와 개별업종 방향 차이가 반복된다.
- 전국 동일업종 benchmark와 구성·피크 신호로 확인 순서를 만들 수 있다.
- 외부자료는 일부 원인 후보와 공급 맥락을 좁히는 데 사용할 수 있다.

## 주장 불가

- CNT 감소가 고객 이탈이라는 단정
- 건당 결제금액 하락이 가격·이익 하락이라는 단정
- 연령·업종 집중이 위험이라는 단정
- 지역×업종 신호가 특정 점포에도 동일하다는 단정
- 폐업확률·예상 매출증가율·검증된 개선효과

## 남은 검증

- 일반 LLM과 진단절차 LLM의 동일조건 비교
- 전문가·점주 블라인드 평가
- 실제 점포 POS·고객·상품·영업정보 연결
- 개선 선택지 실행 전후 KPI 측정
- 12~24개월 또는 전년동월 BC 데이터 확보
